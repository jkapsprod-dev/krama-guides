# Referral code

**What it is:** A short code you can share with friends who are planning a wedding. It never shows them who you are.
**Why you'd use it:** Your cousin's roka is next month, and she asks how you planned so calmly. You give her your code.

**Reward:** When a wedding that used your code has paid, and the refund period has passed, your wedding gets the AI assistant. The assistant is an add-on. You can see it on **Plan & add-ons** in **Settings**.

Hosts can see and use this part. The page is under **Codes & planner**.

## How to share your referral code
1. Open **Settings**, then **Codes & planner**. On a phone, tap **More** first.
2. Find **Referral code**.
3. Tap **Copy code**.
4. Send it to your friend on WhatsApp. You press send yourself.
5. Check the line below to see how many weddings used it.

**Tip:** Your friend enters the code when they start. Tap **Change code** only if you want a new one. You get one free change.
**Stuck?** Can't see the section? Only a host sees **Referral code**. Ask a host.

## How to use a friend's code
1. Open **Settings**, then **Codes & planner**.
2. Go to **Referral code**.
3. Under **Did a friend give you their code?**, type their code.
4. Tap **Use code**.

**Tip:** Do this early. You can use one friend's code for your wedding.
**Stuck?** It says **You used a friend's code.**? A code is already added. It can't be changed.
