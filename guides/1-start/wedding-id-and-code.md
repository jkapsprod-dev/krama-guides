# Wedding ID and wedding code

**What it is:** Two short names for your wedding. The **Wedding ID** never changes. The **Wedding code** is a short name you choose, and it also makes a short link for guests.
**Why you'd use it:** The hotel asks which wedding the rooms are for, so you read out the Wedding ID. Mausi asks for a link to the function list, so you send the short link.

On its own, the Wedding ID opens nothing and gives nobody access. The Wedding code opens nothing private either.

## How to find and copy your Wedding ID
Hosts and planners can do this.

1. Tap **More**, then **Settings**.
2. Stay on **Data & privacy**. Find the **Wedding ID** card.
3. Tap **Copy**. It changes to **Copied**.
4. Paste it into your message. Do not type it, because the last character can be a symbol.
5. Share it only with people you trust, like your planner or the hotel.

**Tip:** Your planner can use your Wedding ID to ask to join. You decide in **Codes & planner**, and nobody sees anything until you say yes.
**Stuck?** You do not see **Settings** if you are family, a helper or a viewer. Ask a host or planner to copy it for you.

## How to choose a wedding code
Only a host can choose or change the code.

1. Tap **More**, then **Codes & planner**.
2. Under **Wedding code**, find **Choose a code**.
3. Type your code. Use 4 to 20 letters or numbers, like RIYA-ARJUN26. Hyphens can split the parts.
4. Tap **Save code**. You see "Saved" with your code.
5. To change it later, type a new code under **New code** and tap **Change code**.
6. Tap **Yes, change it**.

**Tip:** You get one free change. For 30 days the old code sends people to the new one. After that, the old code is free for anyone.
**Stuck?** If it says "That code isn't available. Try another.", someone else has it. Pick a different one. After your free change, only Krama support can change it again.

## How to choose what the short link shows
Only a host can do this. You need a wedding code first.

1. Open **Codes & planner**. Scroll to **What the short link shows**.
2. In **Names to show**, type the names, like Riya & Arjun.
3. Under **Show on the short link**, tick **The names above**, **Month and city** or **Function names and dates**.
4. Tap **Save**.
5. Scroll up and tap **Copy short link**. Send it to your family.

**Tip:** A guest never sees names, phone numbers, addresses, venues or times on this link. Guests still need their own RSVP link for everything else.
**Stuck?** If it says "Type the names to show, or turn that item off.", fill **Names to show** or untick **The names above**.
