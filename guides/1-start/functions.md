# Functions

**What it is:** Functions is the list of every part of your wedding, like Mehendi, Haldi, Sangeet and Reception, with its date, time and venue.
**Why you'd use it:** Mausi calls to ask what time the Haldi starts. You open the function, read the time and the venue, and send her the details in seconds.

Hosts, planners and family can add and change functions. Helpers and viewers can read them.

## How to add a function
1. Tap **Add a function**. On a phone, it is in the (+) menu. On a computer, open **Functions** first.
2. Type the **Name**, like "Garba night".
3. Choose the **Type**.
4. Pick the **Date**, then **Starts** and **Ends**.
5. Add the **Venue** and **Address**.
6. Tap **Save**.

**Tip:** If a function ends after midnight, just type the end time. Krama knows it is the next day.
**Stuck?** If you can't see **Add a function**, you may be a helper or a viewer. Ask a host to add it for you.

## How to set or change a date
1. Open **Functions**. On a phone, tap **More** first.
2. Find the function under **Date to be set** and tap **Set a date**. To change a date, tap the function, then tap **Edit details**.
3. Pick the **Date**.
4. Choose **Starts** and **Ends**.
5. Tap **Save**.

**Tip:** Add the **Note for guests** in the same form. Guests see it on their RSVP page, so keep private notes in **Notes**.
**Stuck?** A function with no date has no times on its run sheet. Set the date first, then add times.

## How to plan rituals
1. Open **Functions** and tap the function.
2. Tap **Rituals**.
3. On an empty function, tap **Add starter ideas** for a few common steps. Then change them to match your family.
4. To add your own, type the **Step** and the **Family role**, then tap **Add step**.
5. For who brings what, type the **Item**, choose the **List** and the **Side**, then tap **Add item**.

**Tip:** Use **Samagri** for the puja things and **Carry bag** for what each side brings. Tick an item when it is ready.
**Stuck?** Families and traditions differ. Check the starter ideas with your pandit, qazi or granthi before you rely on them.

## How to start from an outline
1. Open **Functions** and tap the function.
2. Tap **Run sheet**. If it is empty, you may see **Start from an outline?**
3. Read the usual order of the function. It has no times yet.
4. Tap **Add these** items, or **No thanks** to hide the offer for good.
5. Open each item and set its time.

**Tip:** Change, time or delete any item. The outline is only a first draft.
**Stuck?** The offer shows once, and only for an empty run sheet. If you don't see it, add items yourself in **Run sheets**.

## How to add a function to your calendar
1. Open **Functions** and tap the function. It needs a start time.
2. Find the facts card. On a phone, it is at the top.
3. Tap **Add to calendar** to download the function to your phone or computer calendar.
4. Or tap **Google Calendar** to add it there.

**Tip:** Do this for every function you are running, so your phone reminds you before the day.
**Stuck?** No button? The function has no start time yet. Use **Edit details** to add one.

## How to print a function's schedule
1. Open **Functions** and tap the function.
2. Tap **Print the schedule**.
3. Check the run sheet on the page that opens.
4. Tap **Print**, or save it as a PDF.

**Tip:** Print one for the pandit and one for the caterer, so everyone works from the same times.
**Stuck?** The page says "Nothing on this run sheet yet."? Add the function's items in **Run sheets** first, then print again.
