# Budget

**What it is:** The **Budget** tab in **Money** is where you say how much you plan to spend on each category, like venue, food and decor.
**Why you'd use it:** Papa asks how much the wedding will cost. You set a number for each line once. Later you can see how much is left.

**Who can see this:** Hosts, planners and family see and change the budget. Helpers and viewers never see it. Krama only records your plan. It does not hold or move money.

## How to set your budget
1. Open **Money**. On a phone, tap **More** first.
2. Tap the **Budget** tab.
3. Type the planned amount next to each category. Write it like 2,50,000 or 2.5L.
4. Watch **Total** at the bottom. It adds up as you type.
5. Tap **Save budget**. You see "Budget saved."

**Tip:** Leave a line empty if you are not sure yet. You can come back and change any number.
**Stuck?** Nothing is saved until you tap **Save budget**. If a line shows "Please enter an amount like 2,50,000 or 2.5L.", fix that line and save again. If you land on Home instead, the wedding is read-only, so budget changes are switched off.

On a new wedding with no expenses, the **Money** page also shows an **Edit budget** button. It opens the same page.

## How to start from a typical split
1. Open **Money**, then the **Budget** tab.
2. Find the card **Start from a typical split?** It names the budget range you picked when you set up.
3. Tap **Fill in a typical split**.
4. Read the filled numbers. Change any of them.
5. Tap **Save budget**.

**Tip:** The split is only a starting point. Change the venue and food lines to match your real quotes.
**Stuck?** The card shows only if you picked a budget range when you set up, and only while nothing is planned yet. If you do not see it, type your amounts yourself.

## How to add or rename a category
1. Open **Money**, then the **Budget** tab.
2. To add one, scroll down to **Add a category**.
3. Type the **Category name**.
4. Under **Inside**, choose **Top level**, or pick a group. You can also choose **New group…** and type its name.
5. Tap **Add**. The new line appears in the list.
6. To rename, tap the pencil next to a name. Type the new name. Tap the tick, called **Save name**.

**Tip:** In the same box you can add a **Note (optional)**, like "includes the band's travel".
**Stuck?** Adding and renaming save at once. They do not wait for **Save budget**, so tap **Save budget** for your amounts as well. The bin icon removes a category. Its expenses stay, with no category.

## How to split shared costs between the families
1. Open **Money**, then the **Budget** tab.
2. Under a line's amount, find the **Who pays** list. Choose **Bride’s side**, **Groom’s side** or **Shared**.
3. On a **Shared** line, a **Bride %** box appears. Type the bride's share, like 60. The rest goes to the groom's side.
4. Do the same for the other lines.
5. Tap **Save budget**.
6. Open the **Sides** tab to see each family's planned amount.

**Tip:** To fill every shared line at once, use the typical split card. Tick **Split shared lines**, type **Bride’s family carries (%)**, then tap **Fill in a typical split**.
**Stuck?** If you see "Please enter a share from 0 to 100, or leave it empty.", change the **Bride %** to a number from 0 to 100.
