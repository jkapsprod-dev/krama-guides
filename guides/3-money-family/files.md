# Files

**What it is:** A private shelf for your contracts, receipts, lists and pictures, kept with your wedding.
**Why you'd use it:** The caterer's signed quote is in someone's email and the seating list is on someone's phone. Put them in one place and everyone who needs them can find them.

**Who can see this:** Hosts, planners and family see all files. Money files, like receipts and anything linked to a vendor, expense or payment, are only for hosts, planners and family. Viewers can open every file that is not a money file. Helpers see only files linked to their own tasks, and never money files.

## How to upload a contract or list
1. Open **Files**. On a phone it is under **More**, in **Keepsakes**.
2. Tap **Upload files**.
3. Choose one or more files from your phone or computer. You can also drop them on the box on a computer.
4. Wait for "Uploaded." next to each file name.
5. Tap a file in the list to see its details.

**Tip:** Files can be images, PDF, Word, Excel or CSV, up to 20 MB each. Use the filters **Documents**, **Receipts**, **Images** and **Lists** to find one fast.
**Stuck?** If you see "That file is over 20 MB", shrink it or split it. "Please choose an image, PDF, Word or Excel file" means the type is not allowed. Only hosts, planners and family see **Upload files**. If the wedding is read-only, nobody can upload.

## How to link a file to a function, task, vendor or guest
1. Open **Files** and tap the file.
2. In the details, find **Link to**.
3. Pick **Function**, **Task**, **Vendor** or **Guest**.
4. In the second box, pick which one, for example the Haldi function.
5. Tap **Save**.

**Tip:** You can also add a file straight from a function page, a task page or a vendor page, in its **Files** section. A helper can add files this way on their own tasks.
**Stuck?** A file linked to a vendor is marked as money by itself, and the box is locked. Files made from an expense or a payment are locked too. If **Save** is grey, pick which function, task, vendor or guest first.

## How to hide money files from helpers and viewers
1. Open **Files** and tap the file, like a caterer quote with rates.
2. Find the box **Has money details — hide from helpers and viewers**.
3. Tick it.
4. Tap **Save**.
5. The file now shows a **Money** tag in the list.

**Tip:** A file shows to helpers only if it is linked to their own task and is not marked as money. Check each file before you link it to a helper's task.
**Stuck?** If the box is ticked and grey, the file is linked to a vendor, expense or payment, so it is hidden already. You cannot untick it.
