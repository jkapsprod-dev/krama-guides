# Feature inventory · [[README]] · [[DECISIONS]]

Every feature a person can use in Krama Events, from the live code in `app\` (branch `main`, commit `173c54bd`, 14 Nov 2026), grouped by lane. Names are the ones people see on screen (`app\messages\en.json`, `app\design\NAVIGATION.md`). Live or not follows `app\docs\memory\status.md`.

**How to read the table**

- **Who:** couple/family (hosts, family, and viewers who only read), helper, guest, planner, vendor, admin.
- **Tasks:** the "How to …" tasks a guide note should cover. Button and tab names are in **bold**.
- **Live?**
  - **Live:** the guide gets a video script.
  - **Live, BETA:** live, with a BETA badge on screen.
  - **Live, opt-in:** live, but off until someone switches it on, so the guide says how.
  - **Planned:** switched off, off sale or "coming soon". The note gets `status: planned` and no video.
- **Help article:** which of the 17 website help guides (`app\docs\plans\website-help-articles.md`) already cover it. Lanes reuse their text.
- **Code files:** paths start at `app\`.
  - `W/` = `app/w/[workspaceId]/`
  - `B/` = `app/business/[orgId]/`
  - `R/` = `app/rsvp/[token]/`

**Counts:** 95 features.

- **Live:** 92, of which 4 are BETA and 5 are opt-in.
- **Planned:** 3. **Plan & add-ons** is live for viewing, but buying is planned.
- **By lane:** Lane 1: 20 · Lane 2: 19 · Lane 3: 18 · Lane 4: 16 · Lane 5: 22, plus 7 admin console notes in `_internal`.

## Things every lane should know

- **Krama never sends WhatsApp messages by itself.**
  - Every WhatsApp and most emails open the person's own WhatsApp or email app with a ready message, and they press send. The WhatsApp Business API is not built (on hold).
  - The one exception is **Schedule email** in **Personal messages**, which Krama sends at the family's local time.
  - Guides must say "you press send".
- **Everything is free during the pilot.** The pilot switch is on, and every add-on is off sale.
  - Features that need an add-on (assistant, voice, photos) work today because the pilot grants them.
  - Guides say "it's an add-on" and how to turn it on, with no prices (Appendix C).
- **Languages:** English is reviewed. The other 8 (Hindi, Hinglish, Marathi, Gujarati, Tamil, Marwari, Konkani, Punjabi) show **BETA**. Guides and button names are written in English.
- **Words:**
  - Say "functions", never "events".
  - Say "your wedding", never "workspace". Some help articles still say "workspace", so fix it when reusing them.
- **On a phone,** most sections sit under **More**. The bottom bar shows:
  - Host, planner and family: **Home · Guests · (+) · Tasks · More**
  - Helper: **Home · Tasks · (+) · Event day · More**
  - Viewer: **Home · Functions · Guests · More**
- **Who can do what (wedding app):**
  - Host and planner manage settings and members.
  - Host, planner and family edit, and see money.
  - Helpers see only their own tasks, the guests they're given, and doors.
  - Viewers read only.
  - Helpers and viewers never see money.
