# Krama guides

Simple user guides and short how-to videos for every section of Krama Events, written so an 8th grader can follow them.

**You only paste prompts.** Start with [[START-HERE]] (the checklist); the prompts are in [[PROMPTS]].

- **Where we are:** [[STATUS]]
- **Decisions:** [[DECISIONS]]
- **Guide template:** [[guides/_template]]
- **All guides (index):** `guides\README.md` (started in 1A, completed in 3A)

## How a video is made

1. **Playwright** clicks through the real app with made-up data and records it.
2. **OpenMontage** makes the voice for each step and adds soft music.
3. **HyperFrames** adds the Krama look: intro title, highlights, captions, end card.

## What a note's status means

| status | meaning |
|---|---|
| `draft` | Written from the live code, not yet checked on the real app |
| `final` | Checked on the real app, with screenshots and finished videos |
| `planned` | Feature is switched off or off sale; never published |
| `removed` | Feature no longer in the app; kept for history |
